참가자 흐름

  1. 예약 페이지에서 사전예약 → 사람마다 예약번호 6자리 1개 (당일 예약 불가)
  2. 매표소에서 별빛정원 입장권(유료) 구매 → 일반 관람객과 같은 입구로 입장 (예약자 전용 입구 없음)
  3. 정원 안 금찾기 시작 표식에 휴대폰 접촉 → 본인 예약번호 입력 → 시작 (1인 1일 1회)
  4. 5색 별 표식을 찾아 접촉 → 이야기 읽고 퀴즈 풀기, 소원별은 소원 쓰기 → 별 5개 완성 시 뽑기권
  5. 경품 수령소에서 승인코드 받기 → 본인 휴대폰으로 뽑기 → 그 자리에서 경품 지급 (뽑기권은 당일 23:00까지)
  6. 별조명 체험(1인 2,000원, 매표소에서 팔찌)과 간이장터는 별찾기 전후 언제든 이용

모든 포지션 공통 원칙

  • 확률·당첨률을 말하지 않습니다. "언제 금이 나와요?"에는 "경품은 시간대별로 순서대로 배정됩니다"로만 답합니다.
  • 특정 별이 금이라는 말을 하지 않습니다. 금은 별 5개 완성 후 뽑기에서만 나옵니다.
  • 예약하지 않은 분에게 참여를 약속하지 않습니다. 금찾기는 사전예약자만 참여합니다.
  • 개인정보를 소리 내어 읽지 않습니다. 이름·휴대폰 번호·예약번호는 화면으로만 확인합니다.
  • 답을 모르는 질문은 추측하지 말고 현장 총괄에게 넘깁니다.
