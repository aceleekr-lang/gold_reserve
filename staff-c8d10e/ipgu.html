진행요원① 입구안내·예약확인

진행요원 1명 · 시작 표식 옆
공통 안내현장 총괄① 입구안내·예약확인② 별조명 체험③④ 경품 수령소매표소 협조간이장터 부스

금찾기 시작 표식 옆에서 사전예약자가 본인 예약번호로 막힘없이 시작하도록 돕습니다. 예약하지 않은 분에게는 참여 불가를 정중하게 안내합니다. 운영 시간표는 공통 안내 페이지에 있습니다.

시간별 할 일

  • 금찾기 시작 전 (10월 19:30~20:30): 일찍 온 분께 "20:30에 시작합니다. 그동안 별조명 체험과 간이장터를 즐겨 주세요"라고 안내하고, NFC 설정과 예약번호를 미리 준비시킵니다.
  • 시작~22:00: 시작 도움, 오류 대응.
  • 21:50: "신규 시작은 22:00에 마감됩니다" 안내.
  • 22:00 이후: 새로 시작할 수 없음을 안내. 이미 시작한 분은 23:00까지 계속할 수 있습니다.

시작 도와주기

  1. "금찾기 사전예약 하셨나요?" 확인합니다. 별빛정원 입장권과 금찾기 예약은 별개입니다.
  2. 휴대폰을 준비시킵니다.
    • 안드로이드: 설정에서 NFC 켜기, 휴대폰 뒷면 가운데를 표식에 대기
    • 아이폰: 저전력 모드 끄기, 화면을 켜고 휴대폰 윗부분을 표식에 대기
    • 인식이 안 되면 표식 안의 작은 QR을 카메라로 찍기
  3. 시작 화면에 본인 예약번호 6자리를 입력합니다.
  4. 동반자도 각자 자기 휴대폰으로 자기 번호를 넣습니다. 휴대폰 1대로 1회만 참여할 수 있어, 본인 휴대폰이 없는 분은 참여가 제한됩니다.
  5. 시작 후 나오는 참여번호(복구용)는 예약번호와 다릅니다. 화면 캡처를 권합니다.

앱을 닫았다가 다시 시작 표식에 대면 이어서 진행됩니다. 예약번호를 다시 쓰지 않습니다.

예약번호를 모를 때

  1. 예약 페이지(goldreserve-pi.vercel.app) → 예약 조회 → 이름 + 휴대폰 번호 → 사람별 번호가 나옵니다. 동반자 이름으로도 조회됩니다.
  2. 동반자가 자기 번호를 모르면 대표자 휴대폰에서 조회해 알려 줍니다.
  3. 그래도 안 되면 아래 [현장 확인] 탭에서 찾습니다. 이름과 휴대폰 뒷자리 4개가 모두 맞을 때만 번호를 보여 줍니다.

예약하지 않은 분

  • "금찾기는 100% 사전예약제라 예약하지 않으신 분은 오늘 참여가 어렵습니다. 별빛정원 관람, 별조명 체험, 간이장터는 이용하실 수 있어요."
  • 다음 주말 예약: 매주 월 09:00 ~ 금 17:00, 예약 페이지에서 선착순.
  • 추가 접수 링크는 총괄이 정합니다. 진행요원이 임의로 알려 주지 않습니다.

[현장 확인] 탭 쓰는 법

  1. goldreserve-pi.vercel.app/admin 에 접속해 현장 PIN을 입력합니다. PIN은 총괄에게 받습니다.
  2. [현장 확인] 탭에서 이름 또는 휴대폰 뒷자리 4개로 찾습니다. 현장 PIN으로는 오늘 명단만 보입니다.
  3. 사람별 예약번호와 입장 여부(✓)를 확인합니다.
  4. 입장 취소는 휴대폰 고장 등으로 다시 시작해야 할 때만, 총괄 확인 후 누릅니다.
체크 표시는 이 휴대폰에만 저장됩니다.
